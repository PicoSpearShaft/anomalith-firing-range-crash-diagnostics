## 🎯 What This Does

This project documents how to recognize and troubleshoot **firing range crash diagnostics** in **ANOMALITH**. It focuses on **Crash after firing-range activity, load transitions and startup errors** with targeted checks, patch awareness, and reproducible testing so players can narrow down the actual cause instead of guessing.

## ✨ Features

- Distinguishes demo-only firing-range crashes from problems on the full release.
- Uses file integrity verification and minimal-step crash reproduction.
- Organizes version, location and Windows error data into a useful bug report.

## 🔎 Symptoms Covered

- The game exits or hangs after a shooting-range sequence.
- A transition from the range to the next area fails.
- A problem reported in the demo appears to recur in the full release.

## 🛠️ Troubleshooting — Step by Step

1. **Confirm which build you have.** Record whether the issue is from the demo or the full release; older demo reports may not describe the current game.
2. **Install updates.** Apply the latest Steam update and restart before reproducing the crash.
3. **Verify installation.** Use Steam’s Verify integrity of game files to rule out missing or damaged local content.
4. **Try a clean reproduction.** Restart, repeat the minimum sequence that triggers the crash and avoid changing several settings simultaneously.
5. **Prepare a useful report.** Record exact game build, location, hardware and any Windows error event associated with the crash.
